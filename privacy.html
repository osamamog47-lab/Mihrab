This Privacy Policy describes how the محراب - القرآن الكريم والتلاوات mobile application handles, processes, and protects user data in compliance with Google Play User Data policies.

1. Personal and Sensitive User Data Collection

محراب - القرآن الكريم والتلاوات does not collect, transmit, or share any personal or sensitive user data (such as names, email addresses, phone numbers, financial information, contacts, or precise location data) to any external servers or third parties. No user account or registration is required to use the app.

2. Secure Data Handling Procedures

We implement strict data handling practices to ensure user privacy and security:

  • Local-Only Processing: All user-generated app data—including reading progress, bookmarks, and app settings—is processed and stored exclusively within the private, sandboxed local storage on the user's device.
  • Encrypted Network Transmission (HTTPS): When the application connects to the internet to stream Quranic audio recitations or fetch public religious metadata from public APIs, all network requests are transmitted securely using standard HTTPS/TLS encryption protocols.
  • No Third-Party Tracking or Analytics: The app does not integrate advertising SDKs, tracking cookies, or behavioral analytics tools.

3. Data Retention and Deletion Policy

Because no personal or sensitive user data is collected or stored on external servers, we do not retain any user records remotely. Locally stored preferences and bookmarks remain on your device only as long as the app is installed. You can delete all app data at any time by clearing the app's storage in your Android device settings or by uninstalling the application.

4. App Permissions

The application only requests the standard INTERNET and ACCESS_NETWORK_STATE permissions strictly necessary to stream audio recitations and check connectivity status.

5. Children's Privacy

محراب - القرآن الكريم والتلاوات is suitable for all ages and does not knowingly collect any personal or sensitive data from children under the age of 13.
